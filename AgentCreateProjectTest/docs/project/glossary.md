# Glosario

| Término | Definición |
|---|---|
| Repositorio de gobernanza | Repositorio central de documentación, trazabilidad y coordinación del proyecto |
| Multi-repo | Modelo donde cada servicio tiene su propio repositorio independiente |
| RTM | Requirements Traceability Matrix |
| Contrato | Definición pública de integración entre servicios |
| Historia de usuario | Unidad funcional de backlog asociada a valor de negocio |
