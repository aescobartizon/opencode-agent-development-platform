# Alcance inicial

## Incluye

- Estructura documental del repositorio de gobernanza.
- Plantillas y ejemplos de requisitos.
- Registro central de servicios vacío.
- Trazabilidad inicial con matriz estructurada única.

## No incluye

- Implementación de microservicios.
- Creación de repos de servicio.
- Contratos reales de APIs.
- Despliegue o infraestructura específica.
