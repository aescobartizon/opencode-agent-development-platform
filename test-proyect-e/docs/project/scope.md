# Alcance inicial

## Incluido en esta fase

- Estructura base del repositorio de gobernanza.
- Documentación semilla del proyecto.
- Trazabilidad inicial y matriz RTM vacía.
- Registro inicial de servicios sin entradas reales.
- Soporte para plantillas, agentes, QA global y operación global.

## Fuera de alcance en esta fase

- Implementación de lógica de negocio.
- Creación de microservicios concretos.
- Definición detallada de dominio funcional sin insumos de negocio.
- Configuración específica de nube por servicio.

## Observación

El alcance funcional concreto deberá definirse mediante sesiones de refinamiento y documentación de negocio posterior.
