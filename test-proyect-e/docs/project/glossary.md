# Glosario inicial

| Término | Definición |
|---|---|
| Gobernanza | Conjunto de reglas, artefactos y prácticas que organizan el proyecto |
| Multi-repo | Modelo donde cada microservicio vive en su repositorio independiente |
| RTM | Requirements Traceability Matrix del proyecto |
| FRS | Functional Requirement Specification |
| Épica | Agrupación de funcionalidad de alto nivel |
| Historia de usuario | Unidad funcional refinada y trazable para implementación |
| Contrato de integración | Definición formal de interfaz entre servicios |
| Cross-servicio | Alcance que afecta a más de un servicio o interacción entre ellos |
