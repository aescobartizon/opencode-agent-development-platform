# Stakeholders iniciales

## Grupos identificados

| Stakeholder | Interés principal | Estado inicial |
|---|---|---|
| Sponsor del proyecto | Alineación estratégica y seguimiento ejecutivo | pendiente de nombrar |
| Product owner o analista de negocio | Definición y priorización de requisitos | pendiente de nombrar |
| Arquitectura de solución | Definición de arquitectura global y decisiones transversales | pendiente de nombrar |
| Equipo de desarrollo por servicio | Implementación en repositorios independientes | pendiente de nombrar |
| QA | Estrategia de validación y cobertura cross-servicio | pendiente de nombrar |
| Operaciones o DevOps | Operación, observabilidad y runbooks globales | pendiente de nombrar |

## Próxima acción

Completar responsables nominales y canales de comunicación durante el primer refinamiento del proyecto.
